# サンリオ スマッシュフェスタ フレンズリーグ

4人総当たりのリーグ表。https://tanidayuya.github.io/sanrio-smash-league/

## 結果の更新
`league.json` を編集する。

- `players`: 4人の名前（順番がA〜Dの番号 0〜3）
- `results`: 試合キー `"i-j"` にスコア `[iの得点, jの得点]`
  - 試合キー: `0-1` `2-3` `0-2` `1-3` `0-3` `1-2`（第1〜6試合）
  - 例: `"0-1": [2, 1]` … プレイヤー0が 2-1 で勝ち
- `updated`: 表示用の最終更新日時（例 `"9/27 21:00"`）
